# 第 4 课 · 从端口拉线、吸附、悬空端

> 状态：已完成并内化。

## 1. 功能

- 从橙色端口按住拖动，拖出一条虚线跟随鼠标。
- 松到另一个端口上：吸附，生成端口到端口的边。
- 松到空白处：生成端口到自由点的悬空边。
- 不能吸附起点自身；原地点击不建边。

## 2. 心智模型

```text
magnet 起点 {cell,port}
→ 临时 target {x,y}（只存在于交互过程，不进 Model）
→ 松手时找最近端口
→ 落点转成引用 {cell,port} 或自由点 {x,y}
```

`connecting` 和拖动一样是临时过程状态，归 `Interaction`；`Model` 只在松手那一刻收到一条 `addEdge`。

## 3. 接口

```js
model.getNearestPort(x, y, radius, { exclude })
// → { nodeId, portId, x, y, distance } | null

model.getTerminalPoint({ cell, port } | { x, y })
// 自由端直接返回坐标

graph.addEdge({ source: {cell,port}, target: {cell,port} | {x,y} })
```

## 4. 代码路径

```text
pointerdown 命中端口 → connecting = {source}
pointermove → View 更新虚线 temp line
pointerup → getNearestPort（排除起点）
  → 有吸附：addEdge(port→port)
  → 空白：addEdge(port→{x,y})
  → 原地：取消
→ 隐藏 temp line
```

## 5. 本课边界

- 不做已有边端点重连（第 5 课）。
- 不做折点、正交路由（第 5 课）。
- 端点优先级：端口命中优先于节点拖动。

## 6. 用户验收

- [x] 从 A 的 out 端口拖出虚线跟随鼠标
- [x] 松到 B 的 in 端口，生成实线边，端点落在端口中心
- [x] 松到空白，生成悬空边，一端在端口、一端在松手点
- [x] 从起点拖出又松在起点附近，不建边、不吸附自己
