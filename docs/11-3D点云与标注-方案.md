# 第 11 章 · 3D 点云视图与 3D 框

> 状态：进行中；当前为 11.1。

## 为什么加这一章

第 1–10 课把图编辑内核的机制在 2D/SVG 上摊开了。智驾标注、具身仿真、数字孪生这类岗位要的是同一套机制跑在 3D 上。这一章不是换领域，是**换渲染后端**。

对照关系（内核不变，后端替换）：

| 第 1–10 课（SVG） | 本章（deck.gl） |
|---|---|
| `viewport = {x, y, zoom}` | 相机 `viewState` |
| `<g transform>` 应用视口 | deck 内部管理投影 |
| 点到线段最短距离 | GPU picking / 射线拾取 |
| `<rect>` / `<circle>` | `ScatterplotLayer` / `LineLayer` / `PolygonLayer` |
| 局部重渲染 | layer diff 自动重绘 |

## 11.1 点云视图与相机状态

- 渲染后端换成 deck.gl（UMD 脚本引入，无打包器）
- 点云用确定性合成数据，不依赖下载
- **相机状态仍保存在我们自己的 `SceneState` 里**，deck 只做渲染（`viewState` 受控模式）
- 引入 3D 命中：deck 的 picking，点选到点后写回我们的 state

验收：

- [ ] 能看到一片点云（地面 + 3 辆车）
- [ ] 可以环绕、俯仰、缩放
- [ ] 点击某个点，状态栏显示它的坐标
- [ ] `SceneState` 里能看到 `viewState` 与 `selected`
- [ ] 相机状态可复位

## 11.2 3D 框数据模型与渲染

框 = 9 个数：位置 3 + 尺寸 3 + 旋转 3。实际数据集多数只用 yaw。用 `LineLayer` 画 12 条棱。

## 11.3 框的创建、选中、拖动

复用第 1–10 课的机制：命中 → 选中 → 拖动 → 提交。预览-提交在 3D 里同样成立。

## 边界

- 不做标注数据格式导入导出（那是产品层）
- 不做语义分割、不做点云地面分割算法
- 第 12 章才做 2D↔3D 投影
