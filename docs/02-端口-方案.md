# 第 2 课 · 端口

> 状态：已完成并内化。

## 1. 功能

节点 A 右侧有输出端口，节点 B 左侧有输入端口；边连接两个端口中心。移动 A 后，端口随节点整体移动，边继续连接端口。

## 2. 心智模型

端口不是独立节点，而是节点内部的归一化锚点：

```js
{ id: 'out', x: 1, y: 0.5, direction: 'right' }
```

- `x: 0` 是节点最左侧，`x: 1` 是最右侧。
- `y: 0` 是节点最上侧，`y: 1` 是最下侧。
- `direction` 表示连线从端口向哪个方向离开。

绝对坐标换算：

```text
portX = node.x + node.width  × port.x
portY = node.y + node.height × port.y
```

## 3. 接口

```js
node.ports = [{ id, x, y, direction }]

model.getPortPoint(nodeId, portId)
// → { x, y, direction } | null

model.getTerminalPoint({ cell, port })
// → { x, y, direction } | null
```

## 4. 严格规则

端点指定了不存在的 port 时返回 `null`，边不渲染；绝不回退到节点中心，否则错误的电气连接会被伪装成正常连接。

## 5. 代码路径

```text
Node.ports 保存归一化位置
→ Model.getPortPoint 换算为画布绝对坐标
→ SvgView 在节点 <g> 内创建 <circle>
→ SvgView 用端口绝对坐标更新边的 <line>
```

## 6. 用户验收

- [x] A 右侧、B 左侧各有一个端口圆点
- [x] 连线两端落在端口中心
- [x] 点击“移动 A”后，A 的端口随节点移动
- [x] 连线仍然连接 A 的端口，而不是节点中心
- [x] 在 Elements 中能找到 `data-port-id` 和 `data-direction`
