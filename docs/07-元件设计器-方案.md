# 第 7 章 · 元件设计器

> 状态：已完成。

## 7.1 基础图元

工具栏创建矩形、圆、椭圆、直线；每个图元是数据对象，View 根据 kind 选择对应 SVG 元素；图元可点选和拖动。

```js
{ id, kind: 'rect', x, y, width, height }
{ id, kind: 'circle', cx, cy, r }
{ id, kind: 'ellipse', cx, cy, rx, ry }
{ id, kind: 'line', x1, y1, x2, y2 }
```

验收：四种工具都能创建；选择后变橙；拖动后只改该图元的数据与 SVG。

## 7.2 SVG 整体背景

上传的 SVG 作为一个不可编辑整体显示，不解析内部 path/rect/style；基础图元和引脚覆盖在背景之上。

## 7.3 不规则轮廓引脚吸附

背景仍是整体资源；元件定义额外保存明确的 `snapOutline` 多边形。鼠标点投影到最近线段，投影点作为引脚位置，线段外法线转换为 direction。不得从背景像素猜轮廓。

## 7.4 曲线 snap path

元件定义提供受控的 `snapPathData`。View 创建 SVG path，调用 `getTotalLength/getPointAtLength` 等距采样为折线，再复用 7.3 的最近线段投影和外法线算法。

## 7.5 视口坐标系

画布引入 `viewport = {x, y, zoom}`。所有内容放进一个 `<g data-viewport>`；平移缩放只改这一个 transform。鼠标输入先用逆变换 `world = (screen − viewport.xy) ÷ zoom` 换算到世界坐标，吸附与引脚全部在世界坐标里计算。滚轮以光标为锚点缩放，平移工具拖动平移。世界坐标始终是定义真值，视口只影响显示。

验收：

- [ ] 滚轮缩放时，光标下的那个世界点保持不动
- [ ] 缩放后点击轮廓，引脚仍精确落在曲线上
- [ ] 平移工具拖动时，背景、图元、轮廓、引脚整体移动
- [ ] 元素中的 viewport transform 只有一个 `<g>` 在变
- [ ] 缩放范围被限制在 0.25 ~ 4
