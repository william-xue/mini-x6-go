## 6.1 空白拖动框选

```text
空白 pointerdown → selecting.start
pointermove       → View 画临时选择矩形
pointerup         → Model.getNodesInRect(rect)
                  → View 标出命中节点
                  → 删除临时选择矩形
```

矩形相交条件：

```text
节点右边 >= 选择框左边
节点左边 <= 选择框右边
节点下边 >= 选择框上边
节点上边 <= 选择框下边
```

验收：

- [ ] 从左上往右下框选可用
- [ ] 从右下往左上反向框选可用
- [ ] 选择框碰到节点一部分也算命中
- [ ] 从节点上按下仍拖节点，不进入框选
- [ ] 松手后临时矩形消失，命中节点保留选中样式
