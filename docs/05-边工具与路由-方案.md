# 第 5 课 · 边工具与正交路由

> 状态：进行中；本章拆成四个独立快照，当前为 5.1。

## 为什么拆分

边工具同时包含命中几何、选择状态、端点重连、折点编辑和路由算法，不能作为一次教学塞完。

## 5.1 边命中、选中、删除

功能：点击细线附近也能选中边，选中后加粗变色；按 Delete/Backspace 删除边。

心智模型：鼠标点不是必须精确落在线的 SVG 像素上，而是计算“点到线段的最短距离”，距离不超过容差即命中。

```js
model.getEdgeAt(x, y, tolerance) → edge | null
```

验收：

- [ ] 点击连线附近 8px 内能够选中
- [ ] 选中边后变粗变橙
- [ ] 点击节点时仍优先选节点
- [ ] 选中边按 Delete/Backspace 后只删除边，节点保留

## 5.2 端点手柄与重连

功能：选中边显示两个端点手柄；拖手柄到其他端口，修改 source/target。

## 5.3 折点手柄

功能：给边增加 vertices；选中边显示折点手柄；拖动后保留手工路径。

## 5.4 正交路由

功能：没有手工 vertices 时，根据端口 direction 生成水平/垂直折线路径；有手工 vertices 时尊重人工结果。
