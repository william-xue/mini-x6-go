# 第 3 课 · 点选、拖动、级联删除

> 状态：已完成并内化。

## 1. 功能

- 点击节点后显示选中边框。
- 按住节点拖动，节点、端口和相连边同步移动。
- 节点选中后按 Delete，节点及其相连边一起删除。

## 2. 心智模型

拖动只需要一个临时状态：

```js
dragging = {
  nodeId,
  offsetX,
  offsetY,
}
```

`offsetX/offsetY` 是鼠标按下位置相对节点左上角的距离。移动时保留这段距离，节点就不会瞬间跳到鼠标左上角。

## 3. 事件链

```text
pointerdown → 命中节点 → 记录 dragging
pointermove → 用鼠标位置减 offset → graph.moveNode
pointerup   → 清空 dragging

Delete → graph.removeNode
       → Model 删除 connected edges
       → SvgView 删除对应 SVG 元素
```

## 4. 本课新增边界

- `Interaction` 只保存交互过程状态，不保存图数据。
- `Model` 仍是节点和边的数据真值。
- `SvgView` 仍只负责 SVG 创建、更新和删除。
- 本课不做框选、多选和端口拉线。

## 5. 用户验收

- [ ] 点击 A 或 B 后只有该节点显示选中样式
- [ ] 从节点内部任意位置开始拖动都不会跳
- [ ] 拖动时端口和相连边同步移动
- [ ] 选中节点按 Delete 后，节点和相连边一起消失
