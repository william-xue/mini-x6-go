## 学习闸门

每课固定顺序：

1. 功能：用户能看到什么
2. 操作：在 demo 里怎么触发
3. 心智模型：数据、状态、职责
4. 接口：先定签名
5. 实现：只写这一课
6. 验证：Agent 给出启动方式和观察点，用户亲自打开浏览器验收
7. 内化：讲回 + 拆坏 + 第三层追问

**上一课内化栏没打勾，禁止实现下一课。**

## 硬约束

- `src` 生产源码 ≤ 3000 行；复杂度超预算时砍功能，不压缩可读性。
- 纯 ES Module JavaScript + 原生 SVG，零运行时依赖。
- 不做插件体系、解析任意 SVG 为可编辑图元、完整 A*、虚拟渲染。
- 每课只新增实现当前验收所需的最短主线。
- 除非用户明确要求，Agent 不代跑浏览器验收。
