# 第 1 课 · 图模型 + SVG 局部渲染

> 状态：已完成并内化。

## 1. 功能

创建节点 A、节点 B 和一条 A→B 的边；修改 A 的位置后，A 的 SVG 元素移动，边的起点自动跟到 A 的新位置。

## 2. demo 操作

1. 打开 demo，看见 A、B 和连线。
2. 点击“移动 A”按钮。
3. A 移动；B 不动；连线自动变化。

## 3. 心智模型

```text
Graph     对外门面：调用者只碰它
Model     数据真值：节点、边实际存在哪里
SvgView   数据投影：把 Model 画成 SVG
```

边只保存引用：

```js
{ source: { cell: 'A' }, target: { cell: 'B' } }
```

移动节点时，不修改边的 source/target。View 重画边时现场向 Model 查询 A、B 的最新中心坐标。

## 4. 接口

```js
const graph = new Graph({ container, width, height })

graph.addNode({ id, x, y, width, height, label })
graph.addEdge({ id, source: {cell}, target: {cell} })
graph.moveNode(id, x, y)
```

## 5. 代码路径

```text
graph.addNode
→ model.addNode
→ emit('node:added')
→ view.renderNode

 graph.moveNode
→ model.moveNode（改 x/y）
→ emit('node:moved')          → view.updateNodePosition（只改 transform）
→ 找 connected edges
→ emit('edge:changed')        → view.renderEdge（重新解析端点、改 line）
```
