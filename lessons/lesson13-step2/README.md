# Lesson 13.2 · 引脚的加、删、拖

## 要解决的问题

13.1 能读轮廓、能放引脚了，但引脚是"一次性的"：

```text
加了就钉死    不能删、不能拖、改不了
只能贴边放    必须点在离轮廓 50 个单位以内，元件内部一大片点不到
大小是写死的  r=6 固定，放大画布后引脚还是那么大，点击手感也跟着漂
放之前没预告  点下去才知道落哪
```

四条合起来就是"能用但不敢用"。

## 心智模型

引脚变成**有生命周期的一类对象**，而不是一次性的一个点：

```text
                悬停到轮廓（可放）
   idle ─────────────────────────► 预览（虚线圈，还没落笔）
     ▲                                   │ 按下
     │ 移开                              ▼
     └────────────────────────────── 已生成
                                         │ 悬停到它
                                         ▼
                                      hover（变大变红 + 冒出 ×）
                                         │ 按下            │ 按下 ×
                                         ▼                 ▼
                                     dragging             删除
                                    （沿轮廓滑动）
                                         │ 松手
                                         └──► 提交
```

落实成两个规则，其余都是实现细节：

```text
① 能不能放 = 贴边（8 个单位以内）或者 落在元件内部
② 拖动 = 把指针位置重新投影到轮廓上 —— 所以引脚永远粘在轮廓上，拖不飞
```

## 落点规则为什么改成"内部也可以"

13.1 用的是 `addPinNear(point, 50)`：离轮廓超过 50 个单位就不给放。
后果是元件内部一大片点起来毫无反应（用户点的是"元件"，程序看的是"离那条线多远"）。

13.2 改成两条：

```text
离轮廓 ≤ 8 个单位        → 可以（贴边微调）
已经落在元件内部          → 也可以，投影到最近的那条边
两者都不满足              → 不给放，避免在空白画布上凭空长出引脚
```

"落在元件内部"用的是**射线法**（`pointInPolygon`）：从该点往右发一条射线，数它穿过
几条边；奇数在内部，偶数在外部。凹多边形照样成立，不需要任何凸性假设。

## 尺寸为什么要按 1/zoom 反算

引脚画在 `viewportLayer` 里，跟着视口一起缩放。所以它的半径是**世界坐标**半径：

```text
r_world = r_base / zoom
```

放大 2 倍后 r 减半，屏幕上看起来还是那么大；点击半径同样按 `1/zoom` 反算，
所以缩放前后手感一致。描边则直接用 `vector-effect="non-scaling-stroke"`，不需要反算。

实测：`zoom=1 时 r=8.1 → zoom=2 时 r=4.05`（比值正好 2）。

## 一个必须绕开的坑：徽标会被自己"晃掉"

徽标画在引脚右上方 17 个单位处，可点范围 9×1.4 ≈ 12.6 个单位。
而引脚的命中半径是 12 —— **两个范围接不上**：鼠标从引脚往徽标走的途中会先离开引脚，
于是"悬停引脚"判定失败 → 徽标被收掉 → 徽标永远点不着。

修法：`pointermove` 里**先判徽标**，再判引脚。只要指针还在当前徽标的可点范围内，就保持 hover。

实测（真指针事件）：

```text
悬停在引脚上        状态 = hover，徽标出现 ✓
把鼠标移到徽标上     徽标还在 ✓，引脚仍是 hover ✓
点徽标              引脚数 1 → 0 ✓
```

## 接口

```js
new Designer({ container, width, height, outline: {...} })

designer.setTool('pin')          // 引脚编辑工具；'pan' / 'select' 原样交给第 7 课
designer.clearPins()
designer.pinSnapshot()           // [{ id, x, y, shapeId, direction }]

model.addPinNear(point)          // 落点规则见上；不满足返回 null
model.removePin(pinId)
model.previewPinMove(pinId, p)   // 拖动过程中：只改数据，发 pin:moved
model.movePin(pinId, p)          // 一次性提交：发 pin:changed
model.getPin(pinId) / model.hitPin(point, radius)
```

事件：`pin:added` / `pin:removed` / `pin:changed` / `pin:moved` / `pin:committed`
