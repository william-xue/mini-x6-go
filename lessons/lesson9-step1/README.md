# Lesson 9.1 · 命令栈与「一次操作」

## 要解决的问题

```text
拖一次实例 = 几十次 pointermove = 几十次 model.moveInstance
撤销应该一次退回原处，不是一像素一像素退
```

## 分层

```text
拖动过程中   直接改 Model        实时反馈，不进历史
pointerup    记一条命令          从哪 → 到哪
撤销         把命令倒过来执行
重做         把命令正过来执行
```

## 命令是纯数据

```js
{
  type: 'instance:move',
  label: '移动 instance-1',
  id: 'instance-1',
  from: { x: 30, y: 20 },
  to: { x: 110, y: 60 },
}
```

没有函数。**「怎么执行」不在命令里，而在解释器里**：

```js
// commands.js
applyCommand(model, command)   // 正着做
revertCommand(model, command)  // 倒着做
```

页面底部的「历史栈里的命令」面板就是这份数据的实时快照。

## 撤销栈是什么

就是一个**叠盘子**，后放先拿：

```text
操作1：A (30,20) → (110,60)
操作2：B (300,20) → (200,90)

撤销栈（顶在上）
│ B: (300,20) → (200,90) │ ← 顶
│ A: (30,20)  → (110,60) │

按 Cmd+Z → 拿走顶上那条，倒着执行 → B 回 (300,20)
再按一次 → 再拿一条 → A 回 (30,20)
```

## 命令能序列化，意味着什么

因为命令是纯数据，理论上**历史栈本身也能存进文件、也能通过网络传**。这一步我们没做，但它是数据版命令的直接好处。（对比：如果命令自带函数，就完全做不到。）

## 验收

- [x] 拖一次实例，历史只 +1
- [x] 撤销回到拖动前的位置
- [x] 重做回到拖动后的位置
- [x] 拖回原处不入历史
- [x] 新操作清空重做栈
- [x] `Cmd/Ctrl+Z` / `Cmd/Ctrl+Shift+Z`
- [x] 未知命令类型会显式报错，不静默忽略
